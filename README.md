# pdfproc

Локальный pipeline для извлечения текста из PDF в Markdown. Работает полностью офлайн через [Ollama](https://ollama.ai) + vision-модели. Никаких облачных API, никакой привязки к провайдеру.

Оптимизирован для сканированных документов (кириллица, таблицы, многостраничные секции). Подходит для любого LLM-инструмента: Claude, Cursor, Codex, VS Code Copilot — любой может вызвать скрипт и получить структурированный Markdown.

## Как это работает

Два прохода:

1. **`manifest`** — быстрая классификация каждой страницы (тип + язык + краткое описание), dpi=150
2. **`vision_extract`** — полное извлечение текста в Markdown, dpi=200, по результатам манифеста

Выход: папка с `.md`-файлами по секциям + `README.md` с индексом для навигации агентов/RAG.

## Установка

```bash
# 1. Установить Ollama: https://ollama.ai
# 2. Скачать vision-модель
ollama pull qwen2.5vl:7b

# 3. Установить зависимости (Python ≥3.10)
pip install -r requirements.txt
```

## Быстрый старт

```bash
# Шаг 1: манифест (классификация страниц)
python pdf_processor.py manifest document.pdf ./output

# Шаг 2: извлечение текста
python pdf_processor.py vision_extract document.pdf ./output
```

Результат — папка `./output/` с файлами вида `01_title.md`, `02_contract_header.md`, `03_pricing.md` и `README.md` — индекс удобен для RAG-пайплайнов и навигации любых AI-инструментов.

## Аргументы

```
manifest <pdf> <out>          Классифицировать страницы
vision_extract <pdf> <out>    Извлечь текст по манифесту
info <pdf>                    Информация о PDF без запуска модели
qa <pdf> <out> <вопрос>       Ответить на вопрос по документу

Общие опции:
  --model MODEL         Ollama vision-модель (по умолчанию: qwen2.5vl:7b)
  --pages N или N-M     Обрабатывать только указанные страницы
  --force               Игнорировать кеш, пересчитать всё заново
  --lang ru|kz          Фильтр по языку страниц
  --skip-types TYPES    Пропустить секции указанных типов
  --only-types TYPES    Обрабатывать только указанные типы
  --split-by-section    Разбить вывод на отдельные .md по секциям
  --think               Включить режим размышлений при чтении страниц
                        (по умолчанию выключен для thinking-моделей вроде qwen3.5)
```

## Возобновление после сбоя

Каждая страница кешируется в `<out>/.pdfproc_cache/NNNN.json` сразу после извлечения. При повторном запуске уже обработанные страницы загружаются из кеша. Флаг `--force` отключает кеш.

```bash
# Прервалось на странице 150 из 300 — просто запустить снова:
python pdf_processor.py vision_extract document.pdf ./output
```

## Переменные окружения

| Переменная | Описание | По умолчанию |
|------------|----------|--------------|
| `OLLAMA_HOST` | URL Ollama-сервера | `http://127.0.0.1:11434` |

## Рекомендуемые модели

| Модель | VRAM | Лучше всего для |
|--------|------|-----------------|
| `qwen2.5vl:7b` | ~8 GB | Документы рус/каз, таблицы — проверено |
| `qwen3-vl:8b` | ~8 GB | Новее, 32 языка OCR, основной кандидат |
| `qwen3.5:9b` | ~8 GB | Vision+thinking, медленнее но точнее |
| `gemma3:12b` | ~10 GB | 140+ языков |

## Требования

- Python ≥ 3.10
- [Ollama](https://ollama.ai) с загруженной vision-моделью
- GPU с ≥8 GB VRAM рекомендуется (работает и на CPU, но медленнее)
